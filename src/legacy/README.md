# Retro arcade portfolio (archived)

The original jet-menu game portfolio lives in `RetroPortfolioApp.js`.

To run it again temporarily, change `src/App.js` to:

```js
import RetroPortfolioApp from './legacy/RetroPortfolioApp';
export default RetroPortfolioApp;
```

`Game.js`, sounds, and related components remain in `src/` for that build.
